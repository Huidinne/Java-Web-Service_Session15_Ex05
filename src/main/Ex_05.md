# Phần 1 - Phân tích logic

Trong Spring Boot, `@RestController` là annotation được sử dụng để xây dựng các RESTful API. Annotation này là sự kết hợp giữa `@Controller` và `@ResponseBody`, giúp dữ liệu trả về từ các phương thức được tự động chuyển đổi thành JSON thay vì render ra các trang HTML. Điều này rất phù hợp với các ứng dụng hiện đại như mobile app hoặc single-page application, nơi dữ liệu được trao đổi chủ yếu dưới dạng JSON.

`@RequestBody` được sử dụng để nhận dữ liệu JSON từ request và ánh xạ trực tiếp vào các đối tượng Java (DTO). Khi client gửi dữ liệu đăng ký hoặc đăng nhập dưới dạng JSON, Spring Boot sẽ tự động chuyển đổi dữ liệu này thành đối tượng tương ứng, giúp việc xử lý dữ liệu trở nên đơn giản và rõ ràng hơn.

`ResponseEntity` là lớp hỗ trợ xây dựng HTTP Response một cách linh hoạt. Thông qua `ResponseEntity`, lập trình viên có thể tùy chỉnh nội dung phản hồi, HTTP Status Code và các Header nếu cần thiết. Ví dụ, khi đăng ký thành công có thể trả về mã trạng thái 201 Created, khi username đã tồn tại có thể trả về 409 Conflict, hoặc khi đăng nhập thất bại có thể trả về 401 Unauthorized.

Sự kết hợp giữa `@RestController`, `@RequestBody` và `ResponseEntity` giúp xây dựng các RESTful API tuân thủ chuẩn HTTP, dễ dàng tích hợp với các ứng dụng client và cung cấp các phản hồi rõ ràng, nhất quán cho người sử dụng.
